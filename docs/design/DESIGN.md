## Brand & Style

The design system establishes an architectural, high-precision administration interface built for executive reporting, restaurant revenue intelligence, and dense operational data streams. 

### Visual Identity & Atmosphere
- **Aesthetic Movement:** Corporate Modernism fused with clean, utilitarian data ergonomics. It replaces ornate ornamentation with structural discipline, hairline dividers, deliberate contrast, and mathematical grid spacing.
- **Atmosphere:** Controlled, analytical, trustworthy, and fast. The interface recedes cleanly into the periphery, granting primacy to live KPI metrics, ApexCharts revenue curves, and dense transaction ledgers.
- **Tonal Character:** Crisp light foundations paired with an authoritative deep-slate navy command pillar (`#1C2434`). Accents deploy an electric royal blue (`#3C50E0` / `#465FFF`) to provide clear interactive focal points without sensory fatigue.
- **Target Audience:** Restaurant group executives, general managers, data analysts, and multi-unit hospitality operators requiring real-time visual clarity and rapid decision-making utility.

## Colors

The palette balances structural enterprise neutrals with sharp chromatic signals dedicated to metric performance, data visualization, and transactional workflows.

### Color Hierarchy & Roles
- **Primary (`#3C50E0` / Variant `#465FFF`):** The operational anchor. Dictates interactive CTA focus, active sidebar indicator ribbons, primary ApexCharts series splines, selected radio pills, and high-priority states.
  - Hover: `#3641F5`
  - Container / Tint: `#ECF3FF`
  - On-Container: `#2A31D8`
- **Secondary (`#1C2434`):** The structural command surface. Powers the iconic dark admin sidebar, deep header bands, and high-density dark containers, creating grounding contrast against light cards.
  - Container: `#F2F4F7`
  - On-Secondary: `#FFFFFF`
- **Tertiary (`#0BA5EC`):** Analytical secondary data series, beverage revenue splits, dining covers, live connection badges, and contextual metadata.
  - Container: `#F0F9FF`
- **Neutral (`#64748B` / Slate):** Defines boundary lines, inactive navigation glyphs, secondary body copy, and tabular headings.
  - Surface Canvas (Light): `#F9FAFB`
  - Surface Card (Light): `#FFFFFF`
  - Outline & Borders: `#E2E8F0` (slate-200) and `#E4E7EC`
  - Dark Mode Canvas: `#101828`
  - Dark Mode Card Surface: `#1D2939` (or `rgba(255, 255, 255, 0.03)`)
  - Dark Mode Outline: `#344054`
- **Semantic Feedback:**
  - Positive Trend / Success: `#12B76A` (Container `#ECFDF3`)
  - Negative Delta / Critical Error: `#F04438` (Container `#FEF3F2`)
  - Warning / Under-capacity: `#F79009` (Container `#FFFAEB`)

## Typography

The typographic hierarchy coordinates the geometric confidence of **Plus Jakarta Sans** for display values and module headers with the systematic legibility of **Inter** for data tables, operational controls, and analytical microcopy.

### Typographic Principles
- **Tabular Numerics:** All currency figures, delta percentages, time codes, and ledger amounts must activate OpenType tabular numbers (`tnum`) to maintain vertical column alignment.
- **Headline Scannability:** Executive KPI values employ tight line-heights (1.2–1.26 ratio) and negative letter spacing to create unified, authoritative visual units.
- **Body & Data Density:** Form labels, table cells, and navigation text utilize Inter at 400 and 500 weights to preserve optical clarity even under sustained data analysis and high-density viewports.
- **Case Conventions:** Table column headers use uppercase formatting with generous tracking (`0.05em`) in `caption` or `label-sm` sizing to clearly distinguish schema headers from row content.

## Layout & Spacing

The dashboard employs a fluid, multi-column analytics grid bound by a fixed or collapsible left navigation command pillar (`290px` expanded, `90px` collapsed) and a sticky `72px` administrative top header.

### Grid & Layout Structure
- **Canvas Shell:** Fluid horizontal space using an 8pt base spacing cadence. Inner canvas padding scales from `1rem` (mobile) to `1.5rem` (tablet) to `2rem` (desktop viewports).
- **Executive KPI Row:** 4-column responsive grid layout (`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`) separated by `1.5rem` gutters on desktop and `1rem` on mobile.
- **Analytics Visualizations Grid:** 12-column subgrid. Typical distribution pairs a 7-column primary ApexCharts revenue trend card with a 5-column target radial gauge, or an 8-column order ledger with a 4-column real-time dining room floor plan.
- **Breakpoints:**
  - Mobile (`< 640px`): Sidebar slides off-canvas into an overlay drawer. Analytics widgets drop to single-column stacking.
  - Tablet (`640px – 1023px`): 2-column KPI arrays; sidebar collapses to an icon-only dock (`90px`).
  - Desktop (`1024px+`): Full multi-column dashboard grid with persistent navigation.
- **Table Density:** Table rows enforce `1rem` vertical padding (`py-4`) and `1.25rem` horizontal padding (`px-5`) to prioritize rapid visual auditing without cramped clipping.

## Elevation & Depth

Visual hierarchy relies on crisp surface layering and hairline borders rather than heavy blur drop shadows, ensuring rapid rendering and sharp focus.

### Layering & Outlines
- **Primary Separation:** Boundary depth is established via 1px low-contrast micro-borders in `#E2E8F0` (slate-200) for light canvas components and `#1D2939` / `#344054` for dark containers.
- **Background Contrast:** The base canvas sits at `#F9FAFB`. Component cards lift forward using pure solid `#FFFFFF`, creating clean spatial differentiation without relying on shadow volume.
- **Shadow Scale:**
  - *Micro Shadow (`shadow-xs`):* `0 1px 2px 0 rgba(16, 24, 40, 0.05)` applied strictly to primary buttons and status pills.
  - *Container Shadow (`shadow-sm`):* `0 1px 3px 0 rgba(16, 24, 40, 0.08), 0 1px 2px 0 rgba(16, 24, 40, 0.04)` applied to white KPI cards and chart containers.
  - *Floating Menu Shadow (`shadow-md`):* `0 4px 8px -2px rgba(16, 24, 40, 0.1), 0 2px 4px -2px rgba(16, 24, 40, 0.06)` reserved for context menus, dropdown pickers, and tooltips.
  - *Interactive Focus Ring:* `0 0 0 4px rgba(60, 80, 224, 0.14)` encircling active form fields and focused controls.

## Shapes

The interface embraces a structured, architectural geometry with restrained edge radiuses that preserve maximum visual real estate and communicate computational rigor.

### Shape Geometry Rules
- **Base Components:** Inputs, standard buttons, table cell wrappers, and segmented control chips adhere to `rounded-sm` (0.25rem / 4px) to `rounded-md` (0.375rem / 6px).
- **Dashboard Containers & KPI Cards:** Primary cards use `rounded-lg` (0.5rem / 8px) or up to `rounded-xl` (0.75rem / 12px) for high-impact analytical wrappers, establishing subtle, modern softened corners that do not drift into casual playfulness.
- **Pill Exception:** Status tags, metric delta trend badges (+14.2%), and user presence avatars utilize full roundedness (`rounded-full` / 9999px) to immediately signal compact metadata status distinct from structural containers.
- **ApexCharts Elements:** Bar chart ends enforce a matching `5px` top radius to echo the container geometry.

## Components

### Buttons
- **Primary:** Background in `#3C50E0` with white text. Height is 44px (`px-4 py-2.5`), corner radius `rounded-md` (6px), micro-shadow `shadow-xs`. Hover state shifts to `#3641F5`; focus triggers the 4px `#3C50E0` halo ring.
- **Secondary / Outline:** Background in `#FFFFFF` with `#E2E8F0` border and `#344054` slate text. Hover shifts background to `#F9FAFB`.
- **Ghost / Icon:** Borderless 40x40px container with `rounded-md`. Hover triggers `#F2F4F7` tint with gray-800 icon tinting.

### Cards & KPI Containers
- **Executive KPI Cards:** Pure `#FFFFFF` surface with 1px border in `#E2E8F0`, `rounded-xl` corner radius, and `1.25rem` to `1.5rem` internal padding. Top row houses a 48x48px `rounded-lg` utility icon square in `#F2F4F7` alongside a contextual 3-dot dropdown. The bottom band presents a bold `30px` revenue total paired with a right-aligned pill delta badge.
- **Chart Widgets:** Includes a distinct header row separated by a hairline border (`border-b border-slate-100`), displaying widget title, temporal filter toggle (Daily/Weekly/Monthly), and export triggers.

### Chips & Delta Badges
- **Pill Badges:** Height 24px, `rounded-full`, horizontal padding `px-2.5`, text `12px` font-medium.
  - Positive Trend: `#ECFDF3` container with `#12B76A` text and upward directional arrow.
  - Negative Trend: `#FEF3F2` container with `#F04438` text and downward directional arrow.
  - Pending / Warning: `#FFFAEB` container with `#F79009` text.
  - Active Metric: `#ECF3FF` container with `#3C50E0` text.

### Form Inputs, Checkboxes & Radios
- **Input Fields:** 44px height, full-width, `rounded-md`, 1px border `#E2E8F0`, background `#FFFFFF`. Text size `14px`, placeholder in `#94A3B8`. Focus state applies `#3C50E0` border and 4px ambient focus ring.
- **Checkboxes & Radios:** 18x18px squared (`rounded-sm`) or circular frames. Unchecked border is `#CBD5E1`. Checked state fills `#3C50E0` with crisp white SVG check/dot indicator.

### Lists & Data Tables
- **Data Tables:** Enclosed inside white `rounded-xl` cards. Header row utilizes `#F8FAFC` background with uppercase `11px` bold slate-500 labels. Data rows feature 16px vertical padding, hairline divider lines, and hover highlighting (`#F8FAFC`).
- **Pagination Footers:** Integrated directly into the card base, featuring record count descriptions on the left and bordered numeric page triggers with chevron controllers on the right.

### ApexCharts Revenue Integrations
- **Bar Visualizations:** Bar width set to ~39% with `5px` top-end border radius. Primary series colored in `#3C50E0` and comparison bars in `#0BA5EC`.
- **Spline Curves:** 2px stroke width with subtle area gradient under curves fading from 45% opacity to 0% at the base axis. Gridlines styled as minimalist `#F1F5F9` dashed lines.
